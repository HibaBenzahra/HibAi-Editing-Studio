INSTALL (Claude desktop app → Code tab, or Claude Code)
  1. Unzip this file. You get a folder called "hibai-studio".
  2. Move that folder into:
       Windows:  C:\Users\<you>\.claude\skills\
       Mac:      ~/.claude/skills/
     (create the "skills" folder if it doesn't exist)
  3. Open a new chat, attach a talking video and say:
       "قاد ليا هاد الفيديو"  or  "edit my video"

Claude checks the tools it needs (ffmpeg, Python, Node.js, Whisper, Chrome) and offers to install
anything missing.
